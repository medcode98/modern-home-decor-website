# Modern Interiors Website

A modern, minimalist home furnishings and interior design website built with **HTML, CSS, and JavaScript**. The project is split into three files for clarity and maintainability.

---

## ?? Project Structure

```
modern-interiors/
¦
+-- index.html   # Main HTML structure
+-- style.css    # Styling and layout
+-- script.js    # Animations and interactions
+-- README.md    # Project documentation
```

---

## ?? Getting Started

1. **Clone or download** this project folder.
2. Make sure all three files (`index.html`, `style.css`, `script.js`) are in the same directory.
3. Open `index.html` in your web browser.

---

## ?? Features

* Responsive, modern layout with grayscale + coral/peach accent colors.
* Smooth animations on load and scroll.
* Interactive product showcase with hover effects.
* Auto-sliding product carousel.
* Newsletter signup form with email validation.

---

## ?? Customization

* Replace placeholder images with your own product or interior images.
* Adjust colors in `style.css` to fit your brand.
* Modify carousel timing in `script.js` (default: 3 seconds).
